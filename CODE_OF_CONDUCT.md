# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind and assume good intent. Everyone here is a volunteer.
- Critique code and ideas, never people.
- No harassment, insults, discriminatory jokes, or sharing others' private information.
- Help newcomers: a "good first issue" is often someone's first open-source contribution.

## Scope

This applies in all project spaces — issues, pull requests, discussions — and when
representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@bartlomiejborzucki](https://github.com/bartlomiejborzucki), using the contact details on
their GitHub profile, or use GitHub's **Report content** option on the offending comment.
Reports are handled confidentially. The maintainer may edit or remove contributions and
temporarily or permanently ban contributors who do not follow this code, following the
Contributor Covenant's enforcement guidelines.
